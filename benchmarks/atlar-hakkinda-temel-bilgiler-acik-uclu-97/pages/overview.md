# Overview

This benchmark measures how well a model explains core horse care, behavior,
and health topics: sleep patterns, handling, hoof care, diet, colic risk,
riding preparation, herd behavior, aging, and feed changes.

Each answer is a short, free-form response (2-3 sentences). It is scored on
how many required key points it covers (`keyword_coverage`) and whether it
covers all of them (`all_keywords`); `overall_accuracy` is their average.

Detailed per-question results are shown for every submission, so you can see
exactly which key points a model missed on each question.
